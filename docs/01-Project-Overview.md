# 项目需求与目标

> 更新日期：2026-08-01 ｜ 当前阶段：v6（评估体系 + 新方法探索 + 下游验证）

---

## 一、项目背景

老师提供了 **330 张严重症状眼底彩照**（重度 DR/4 级），数据无任何标签、单类。项目最初目标为探索 VAE → GAN → Diffusion 生成模型家族产出逼真眼底图。

**为什么严重症状图稀缺是问题：** 现实临床中重度 DR 眼底图远少于轻中度和正常图，导致分类器对重度类样本不足、决策偏颇。本项目的意义在于**合成大量优质重度眼底图来扩充训练集**，缓解这种偏差。

## 二、项目目标（v6 阶段）

> **核心目标：利用 330 张严重症状眼底彩照，训练出「相似但不跟原图一样」的图片，用于扩充数据集、训练 DR 分级分类器（可能也做病灶类型判断）。**

拆解为三件事：

| # | 目标 | 说明 |
|:--|:--|:--|
| 1 | **建立评分标准体系** | 通用指标（FID/召回率等）+ 自设计专用指标，全部要算，先用历史结果重算 |
| 2 | **探索新生成方法** | 不再局限于深度学习：OpenCV+ML、预训练、迁移学习（Stable Diffusion）均可试 |
| 3 | **下游分类器验证** | 合成重度图能否提升 DR 分类器对重度类的性能（TSTR/TRTR） |

## 三、老师反馈（2026-08-01）

| # | 反馈 | 要求 |
|:--|:--|:--|
| Bug 1 | 项目没有像 FID 这样的评分标准 | 通用指标全部要用（FID/IS/KID/Precision-Recall/Density-Coverage/召回率等），自设计的也可以，都要；先用历史训练结果重算一遍，再调研更适合眼底图的评分标准 |
| Bug 2 | 不局限于学术论文推荐的方法/深度学习 | OpenCV+机器学习、预训练、迁移学习（Stable Diffusion）都可以试；目的只有一个——用数据集训练出相似但不相同的图片扩充分类器训练集 |

## 四、验收标准

- [ ] **Phase A**：6 个有 checkpoint 的模型全部跑完两层指标，产出 `evaluation_report.md`（通用层 8 项 + 专用层 7 项）
- [x] **Phase B**：评分标准调研完成，结论并入 `evaluation_report.md`（第二部分），说明"为什么采用这套指标"，回应老师 Bug 1
- [ ] **Phase C**：产出 OpenCV 经典增广扩充集（3~5 倍），传统 ML 可行性结论，SD 微调评估结论
- [ ] **Phase D**：合成重度图显著提升 DR 分类器对 4 级类的 Recall/F1/平衡准确率

## 五、数据集

| 项 | 说明 |
|------|------|
| 原始图 | 330 张严重症状眼底彩照（JPG/PNG 混合，分辨率各异） |
| 训练基准集 | `fundus/_all_images_ORIGINAL/`（330 张方形 JPG，统一处理） |
| 增强版 | 每张 4 几何变体 → 1320 张（`_all_images_256` / `_all_images_much`） |
| 标签 | **无**。全部为重度/4 级，单类 |
| 血管骨架 mask | 330 张 128×128（`generate_project/deep_learning/Fundus-Diffusion/ddpm/conditions/`），条件扩散 + Vessel Dice 评估用 |
| 病灶 mask | 无 |

**下游验证数据：** 分类器训练/测试需要带 DR 分级的公开集（优先 APTOS 2019 / EyePACS），先下载公开集跑通，老师后续提供真实数据替换。
