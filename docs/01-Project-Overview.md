## 一、项目背景

项目最初使用 **330 张严重症状眼底彩照**（KW-IV 级，无标签、单类，网络下载），目标为探索 VAE → GAN → Diffusion 生成模型家族产出逼真眼底图。

**为什么严重症状图稀缺是问题：** 现实临床中重度 DR 眼底图远少于轻中度和正常图，导致分类器对重度类样本不足、决策偏颇。本项目的意义在于**合成优质重度眼底图来扩充训练集**，缓解这种偏差。

**2026-10-16 定位**：整个项目的最终目的是**产出一篇优秀的 paper**；工程实用性降为第二位。论文路线与口径见 [14-Paper-Spine.md](14-Paper-Spine.md)。

## 二、项目目标

> **核心目标：研究小样本眼底生成的失效机理与评估方法（论文路线 A），并以可控 severe 图生成完成 DR 分级数据扩充与下游验证（路线 B）。**

| # | 目标 | 说明 | 状态 |
|:--|:--|:--|:--|
| 1 | **建立评分标准体系** | 通用指标 + 自设计专用指标（两层），综合评分（六维门控） | ✅ Phase A/B |
| 2 | **探索生成方法** | 深度学习 + 传统 ML + 预训练（调研完成），同口径横评 | ✅ C2 / ⏳ 预训练落地 |
| 3 | **下游验证（TSTR）** | 合成 severe 图替换老师数据集翻转副本 → 训练分类器对比 | 🏃 Phase D |
