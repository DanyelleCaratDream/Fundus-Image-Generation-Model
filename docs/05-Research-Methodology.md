# 科研方法论 — 评估指标体系

## 核心立场

**通用指标的价值不是"敏感"，而是"可比性"**（答辩时跟文献对齐），所以必须全算；**医学意义由专用指标承担**（回答"严重症状有没有被保住"）。两层互补。

---

## 一、通用层指标（对标文献，所有生成模型都用）

> **2026-08-01 裁剪决定**：只评"容易拿到、库直接支持"的指标。难评的砍掉——C2ST（要训判别 CNN）、病灶检测 P/R（无标注调阈值不可靠）、病灶面积 Wasserstein（依赖分割）、BRISQUE/NIQE（无参考质量对眼底图意义弱）、Vessel Dice（管线慢）。

| 指标 | 测什么 | 方向 | 实现 |
|:--|:--|:--:|:--|
| FID | 生成分布 vs 真实分布距离 | 越低越好 | pytorch-fid |
| IS | 清晰度 × 多样性 | 越高越好 | pytorch-fid |
| KID | 分布距离（无偏估计） | 越低越好 | 手写多项式核（小样本友好，主动强调） |
| MMD | 分布距离（核方法，小样本稳） | 越低越好 | 手写 RBF kernel torch |
| Precision / Recall | 保真度 / 多样性分解 | 越高越好 | prdc（Kynkäänniemi） |
| Density / Coverage | 保真/多样性（小样本稳） | 越高越好 | prdc（Naeem） |
| 1-NN 双样本测试 | 真图/生成图可分性 | 接近 0.5 越好 | sklearn kNN |
| MS-SSIM | 生成集内部多样性 | 越低越好 | pytorch-msssim（输入 resize 256） |
| LPIPS | 感知相似度（真实 vs 生成最近邻） | 越低越好 | lpips（AlexNet，训练已用） |
| 颜色统计距离 | RGB 均值/方差/直方图保真 | 越低越好 | 手写（CPU 秒算） |

## 二、专用层指标（承担医学意义）

> **2026-08-01 裁剪决定**：本期只评通用层 + 颜色统计（最容易拿到、库直接支持）。以下专用层指标列为**未来可做**（有数据/标注后再上），本期不阻塞评估。

| 指标 | 测什么 | 方法 | 状态 |
|:--|:--|:--|:--:|
| 颜色统计距离 | 色调保真 | 各通道均值/方差 + 直方图距离 | ✅ 本期已做（并入通用层） |
| Vessel Dice | 血管拓扑保真 | 输入 mask → 生成图 → 复用 prep_conditions.py 提取血管 → Dice（仅条件模型） | ⏸ 未来 |
| 血管密度/曲率分布 | 无条件模型的血管替代指标 | 生成图提取血管 vs 真实图统计对比 | ⏸ 未来 |
| 病灶检测 Precision / Recall | 出血/渗出"抓没抓到、准不准" | 颜色阈值（暗红=出血，亮黄白=渗出） | ⏸ 未来（无标注调阈值不可靠） |
| 病灶面积分布匹配 | 症状统计保真 | 真实 vs 生成的病灶面积占比直方图 Wasserstein 距离 | ⏸ 未来 |
| C2ST 真伪分类 AUC | 生成图能否骗过判别器 | 小 CNN 真/假二分类，交叉验证 | ⏸ 未来（要训 CNN，费时） |
| 记忆检测 | 相似但不相同 | 每张生成图对真实集最近邻距离（max SSIM / min L2），防模型背题 | ⏸ 未来 |

> **"召回率"出现两次，答辩要讲清：** 通用层 Precision/Recall = 生成图落没落在真实流形上；专用层病灶检测 Recall = 真实出血点被检出多少。

## 三、落地方案（把定性评分定量化）

```
颜色正确性  →  各通道均值/方差/直方图距离（本期做）
可比性      →  通用层全跑（FID/IS/KID/MMD/P&R/Density/Coverage/1-NN/MS-SSIM/LPIPS）
血管/病灶  →  Vessel Dice、病灶 P/R 等专用层（未来，待标注/管线就绪）
```

## 五、下游验证（Phase D 金标准）

**TSTR vs TRTR**：分别用「纯真实图」和「真实图+合成重度图」训练 DR 分级器，在真实测试集上对比重度类的 Recall / F1 / 平衡准确率。这是"扩充数据集训练分类器"目标的最终验收。
