# 科研方法论

## 评估指标体系

### 1. 定性评估（肉眼观察）
- **真实性**：生成的眼底图是否看起来像真实的视网膜结构（血管、视盘、黄斑）
- **多样性**：不同样本之间是否有足够的差异，还是都长一样（模式坍塌）
- **清晰度**：图像是否清晰锐利，还是模糊/有伪影

### 2. 定量评估
| 指标 | 全称 | 说明 | 方向 |
|------|------|------|------|
| FID | Frechet Inception Distance | 生成图与真实图在 Inception 特征空间的分布距离 | 越低越好 |
| IS | Inception Score | 生成图的类别明确性和多样性 | 越高越好 |

FID 计算方式：
```python
# 使用 torchmetrics 或 clean-fid 库
from torchmetrics.image.fid import FrechetInceptionDistance
fid = FrechetInceptionDistance(feature=2048)
fid.update(real_images, real=True)
fid.update(fake_images, real=False)
print(f"FID: {fid.compute():.2f}")
```

## 实验记录规范

每个实验需记录以下信息：

### 元信息
- 实验编号（EX-001, EX-002, ...）
- 模型名称及版本
- 训练日期和时间
- 训练总耗时
- 实验负责人

### 超参数
- epochs, batch_size, img_size, lr
- 模型特有参数（如 VAE 的 beta, GAN 的 n_critic 等）
- 数据增强配置
- 随机种子

### 训练过程
- Loss 曲线截图（D_loss 和 G_loss 或 recon_loss + KL_loss）
- 训练过程中不同阶段的生成图对比（早期/中期/后期）
- 训练是否稳定（有无模式坍塌、梯度爆炸等）

### 结果
- FID / IS 分数
- 最佳生成样例图（5-10张）
- 最差生成样例图（5-10张）
- 肉眼观察结论

### 结论与反思
- 模型是否适合眼底彩照生成任务
- 优点和缺点分别是什么
- 改进方向

## 论文撰写指南
待研究完成后，科研报告结构建议：
1. 摘要（Abstract）
2. 引言（Introduction）— 眼底彩照生成的研究意义
3. 相关工作（Related Work）— 四大模型家族的文献综述
4. 方法（Method）— 本研究的模型选择与训练策略
5. 实验（Experiments）— 数据集、训练细节、评估指标
6. 结果（Results）— 各模型生成效果对比
7. 讨论（Discussion）— 分析各模型的优劣
8. 结论（Conclusion）— 总结与展望
