# 综合评分方案设计文档（为什么这么设计）

> 本文档解释 `eval/score_scheme.py` 的**每个设计决策背后的为什么**：从需求出发的决策链、每维权重理由（数据 + 文献）、门控动机、归一化选择、指标去留判据，以及已知局限。报告 `research-report/evaluation_report.md` 5.6/5.7/5.8 是精简版，本文档是完整版。
> 更新日期：2026-08-02（公式 v1）

---

## 一、动机：为什么需要综合评分

**问题**：两层 ~30 个指标全测一遍就结束，没有综合结论。`evaluation_report.md` 5.4「加权各维度」只有标题、没有数学公式；人工分是单人不规范肉眼估分（无 rubric、无多人校验）。

**需求**（用户 2026-08-02 提出）：
1. 用人工分做"金标准"，校准各自动指标 → 判断哪些指标贴合人眼、哪些有偏可去除
2. 拿出一套**纯自动**加权综合评分（0-100 总分 + 维度画像），后续新方法（含传统 ML）丢 JSON 重跑即可客观打分
3. 参考医学论文评估 KW-IV 级（最重）高血压视网膜病变生成图的做法

**为什么纯自动**：Phase C 之后会有 OpenCV+ML 等非深度学习方法加入对比，不可能每次都让人眼打分。评分公式一旦固化（写入 `SCHEME`），任何新方法的结果 JSON 放进来重跑即得同口径总分——**可比性是这套方案的核心价值**。

**为什么总分 + 维度画像**：总分给"谁好"的结论，六维画像给"好在哪里/差在哪里"（如 film 多样性满分的代价是抗识破差）——扩增用途需要看维度分布，不只排名。

## 二、为什么用人工分做金标准校准

**文献支撑**（Phase B 调研，报告第二部分）：
- CCDM（眼底扩散模型）：FID 9.3 极低，**资深阅片师仍 100% 识破**（血管僵硬）→ 结构伪影是人工能看出、FID 看不出 → 人工目视是机器指标测不到的"真理来源"
- 专家对 GAN 眼底图整体识破率仅 59% → 人工分有区分度，不是全 100%

**为什么用 Spearman ρ 而不是 Pearson**：N=6 小样本 + 指标量纲各异（FID 180 vs KID 0.1），ρ 是秩相关，只关心排序一致性，不受单调变换影响——我们要的是"指标排序是否贴合人工排序"，不是线性关系。

**为什么加"方向一致率"和"组内最优==人工最优?"**：ρ 反映整体排序，但 N=6 时单个异常值会主导 ρ。补充两个更直观的判据：① 方向一致 = 指标的最好方向是否与人工正相关（如 lower 类指标 ρ<0）；② 组内最优 == 人工最优 = 该指标评出的第一名是否就是人工第一名（film_l1lpips）。**两个判据 + ρ 三者交叉验证**，避免单一统计量误导（这也是早期 Plan agent"τ=0.93"教训的应对：任何结论必须实测复现 + 多判据确认）。

**N=6 统计功效声明**：p<0.1 只作提示不作显著性结论；ρ 的绝对值（±0.7 以上）比 p 更有参考价值。

## 三、为什么六维设计（每维"为什么"）

任务本质：生成 KW-IV 级（最重）高血压视网膜病变图，扩充 DR 分级分类器训练集。所以维度按**"病灶（任务核心）→ 像不像（抗识破）→ 多样性（扩增价值）→ 结构代理（血管）→ 颜色代理 → 记忆保险"**排列：

| 维度 | 权重 | 为什么是这个权重 | 成员指标为什么这么选 |
|:--|--:|:--|:--|
| **D1 病灶保留** | 0.30 | **任务核心**。KW-IV 的病灶（火焰状出血/硬性渗出/棉絮斑）是分类器识别"最重级"的关键信号，病灶溶解 = 生成图对分类任务无用。权重最高 | 出血+渗出各两个指标：Wass 距离（分布对齐）+ 保留率（直接测"病灶溶解"，film_l1lpips=1.137 唯一过 1 的模型，与人工一致）。保留率是本方案唯一直接测病灶存续的指标，权重最高（0.30） |
| **D2 抗识破+分布** | 0.25 | **"像不像真实"**。C2ST ρ=-0.771 实测最贴合人工（判别器 = "人眼能识破吗"的机器版）；KID 无偏且 ρ 最强(-0.886)；FID 是事实标准。扩增用途下，被识破的图污染训练集 | C2ST 权重最高(0.40)因为它直接测可识破性；FID/KID 各 0.25；1-NN 全模型饱和 0.97-1.0 无区分 → 降权到 0.10 |
| **D3 多样性/质量** | 0.20 | **扩增的第二个目的**。生成图不能千篇一律，否则数据增强无意义。Recall 干净分群扩散 vs GAN/VAE（0.44-0.74 vs 0），MS-SSIM ρ=-0.829 显著 | Recall 0.40（分群能力最强）+ MS-SSIM 0.30（ρ 显著）+ IS 0.30（IS ρ=+0.371 且最优==人工最优） |
| **D4 血管结构** | 0.10 | **血管僵硬是人工识破主因**（CCDM 文献），但我们的指标（Frangi 面积占比距离）是低层代理，≠ 真实结构（Betti-0/曲率需高质量 mask，我们没有）→ 低权 | vessel_frac_wass + vessel_dice 各 0.50；Dice 只有条件模型有 → 缺键容错设计必须处理（见六） |
| **D5 颜色** | 0.08 | 医学色偏有生理意义（橙红调 = 血红蛋白吸收），但**VAE 全优证明颜色可被"合法但低信息"地博弈**（VAE 颜色完美但结构糊）→ 低权 | 均值/方差/直方图距离各 1/3；这三个指标在真实图上标定过，是"颜色对"的最直接度量 |
| **D6 记忆风险** | 0.07 | **防复制保险丝**，不是质量计。文献共识：FID 对复制不敏感甚至"变好"（假象），记忆必须独立测。当前全模型复制率 0%（mem_ssim>0.85 = 0%）→ 没有紧迫危险 → 权重最小 | mem_ssim_mean 单一指标即可（NN-SSIM 均值，>0.85 算复制）；ρ=+0.086 方向反（DCGAN"最优"只是因为 SSIM<0 连复制的最低限度都没有）→ 证明它只防事故、不测质量 |

**为什么权重总和 = 1**：保证总分 ∈ [0,100]，且每维贡献即"占总分的百分比"（D1 满分 = 100×0.30 = 30 分），报告/答辩时好解释。

## 四、为什么门控（防"颜色对但结构糊"假象）

**问题实证**：无门控时 VAE=57.9（与 film 58.9 / base_cj 58.5 同簇，混到中游）。VAE 靠什么拿分？D1=0.82（病灶保留率接近 1——它把颜色区域平滑成"看起来有病灶"）、D4=1.0、D5=1.0（颜色全优）。但 C2ST=0.999（几乎完美可识破）、Recall=0（无多样性）——**这些"病灶/血管/颜色匹配"只是颜色统计巧合，不是真实结构**。

**门控设计**：`R(k) = D2(k)`，D1/D4/D5（可被低层代理博弈的维度）乘 R：
```
Score(k) = 100 × [0.30·D1·R + 0.25·D2 + 0.20·D3 + 0.10·D4·R + 0.08·D5·R + 0.07·D6]
```
语义：**"结构匹配"只有在"整体像真实"时才可信**。C2ST≈1.0（一眼假）时，病灶/血管/颜色匹配全部打折。

**为什么门控选 D2 而不是别的**：D2 是"可识破性"的集合（C2ST 判别器 = 人眼识破的机器版 + 分布距离），是唯一直接测"像不像"的维度。D1/D3 是内容维度、D6 是保险，都不该做门（一个"病灶全对但一眼假"的模型就该被压分——这正是 VAE）。

**门控对 τ 无提升（0.600 vs 0.733），为什么还要**：τ 是排序指标，VAE 本来就在人工分末尾，门控不改变它的排名。门控的价值在**绝对分数的语义正确性**：25.7 跌入失败带（<30），让"总分 57.9"这种误导性中游分数不再出现。**排序正确 ≠ 分数可信**——这是方案与"只追求 τ 对齐"的本质区别。

## 五、为什么归一化这么设计

**为什么 min-max 跨模型相对归一化**：指标量纲天差地别（FID ~180 vs KID ~0.1 vs 保留率 ~1），必须无纲化才能加权。min-max 把每个指标的最优模型映射到 1、最差到 0，**"组内相对最优"**，不假设指标分布。

**为什么方向反转**：让每个指标归一化后都是"越大越好"，加权才有意义。

**为什么 close1（保留率）用 `max(0, 1-|x-1|/scale)`**：保留率的最优是 1.0（不多不少）。|x-1| 是"偏离完美"的距离；scale 取 `max(1, max|x-1|)` 防大离群值（DCGAN 渗出保留率 40 倍会把 scale 拉爆，其他人全挤到 0 附近）。

**为什么 close05（1-NN）用 `1-|x-0.5|/0.5`**：1-NN 最优 0.5（不可分）。但所有模型都 0.97-1.0 → 归一化后贡献≈0，自动实现"降权"效果（不额外改权重）。

**为什么缺失键容错**：① 维内缺失（如只有条件模型有 vessel_dice）→ 维内权重在存在指标上归一化；② 整维缺失（新方法只跑通用层，无 fundus JSON）→ 该维权重在所有存在维上重归一化，总分仍落 0-100。**设计意图：新方法最低成本接入**——只跑最便宜的一层指标也能出分，分数口径随层数变粗但不断裂。

## 六、指标去留判据（哪些有偏、为什么）

**判据原则**（写入 `CANDIDATE_METRICS`，脚本与报告一致）：

| 指标 | 实测 | 判据 | 为什么 |
|:--|:--|:--|:--|
| KID / C2ST / MS-SSIM | ρ 显著（-0.89/-0.77/-0.83） | 计分（高权） | 贴合人工，方向一致，最优==人工最优（KID/C2ST） |
| FID / Recall / IS | ρ 中等（-0.49/+0.58/+0.37） | 计分（中权） | 方向一致；FID/IS 最优==人工最优 |
| **LPIPS-NN** | **+0.200 方向反**（VAE 悖论） | **去除出计分** | VAE"平均脸"平滑使感知距离小但结构全糊 → LPIPS 对眼底图有偏。**单指标反例 + 方向反 + 最优==人工最差，三重证据** |
| 颜色三指标 | ρ≈-0.1 | 计分但门控+低权 | 可被 VAE 博弈（"合法但低信息"）；门控后 VAE 拿不到分 |
| 血管占比 Wass | +0.771 方向反 | 计分但门控+低权 | VAE 靠颜色阈值"看起来像血管"骗分；结构代理不可信时由 D2 门控兜底 |
| 1-NN | 饱和 0.97-1.0 | 降权 0.10 | 无区分度，但保留作"相似但不相同"的语义锚点 |
| 记忆 NN-SSIM | ρ=+0.086 | 计分（权重最小 0.07） | 保险丝而非质量计，防复制事故 |
| Precision/Density/Coverage/MMD/BRISQUE | ρ 弱 | 仅参考 | 小样本 k-NN 保守（Precision 普遍 0-0.05），进计分只会稀释噪声 |

**为什么"仅参考"指标不删除**：报告/图表里保留全貌（plot_metrics 仍画 11 项通用层），只从计分公式里剔除——**报告完整性与公式纯净性分离**。

## 七、已知局限与未来扩展

1. **N=6 校准是小样本**：权重含主观判断 + 统计功效低。模型库扩大（Phase C2 加入）后需**重跑校准**（`python eval/score_scheme.py` 自动输出新 ρ 表），必要时调权重（改 `SCHEME` 需同步报告 5.7）。
2. **相对分数**：min-max 归一化使分数相对于当前比较集——新方法加入后旧分数会平移。跨批次比较请用**同批次内排名 + 维度画像**，不要比绝对值。
3. **人工分是单人估分**：无 rubric、无多人校验（用户确认直接使用 + 标注局限）。Phase D 的 TSTR/TRTR 下游验证是终极金标准，可能修正本方案的权重。
4. **门控是硬编码**：D2 缺失时自动禁用（R=1），此时 D1/D4/D5 无门控——新方法务必优先跑含 C2ST 的专用层。
5. **不回答"为什么人工偏爱 film"**：指标-人工分歧簇（film 人工第 2 但客观最差）是真实分歧，方案如实反映，最终裁决留给 TSTR/TRTR。
