## Phase C2（当前）：传统 ML 生成

**目标**：验证"非深度方法能否生成可用的重度眼底图"，产出否定性结论（纯基线）+ 亮点（组合）。

**步骤**（详细见 `machine_learning/docs/05-Execution-Plan.md`）：
1. 3 个确定性基线：PCA / GMM / 补丁拼接，各 60 张（2026-08-18 新规，不再 300）→ 评估 → 打分（预期 0-20 分，否定性底）
2. 2 个高价值组合：泊松病变重排 / Retinex 光照交换，各 60 张 → 评估 → 打分（预期"相似但不相同"亮点）
3. 复制检测三件套（质检门控）
4. 报告 C2 章节（按 `machine_learning/report/05-paper-structure.md`）

**前置**：用户确认文档体系后启动实验。

## Phase C3（可选）：预训练 SD LoRA

**前置条件**：C2 完成后按需评估；先读 `pretrained/report-pretrained-lit.md`。
**核心调研**：8GB VRAM 下 SD LoRA 的可行性（LoRA 512 输出 vs 128 评估口径对接）。
**预期定位**：价值锚定"改善严重类特异性/平衡度"，不追求超越经典增广的判别力。

## Phase D（终极）：DR 分级分类器

**前置**：330 张标注（老师/医生，KW I-IV 级）+ 分级细节确认。
**内容**：分类器（纯分类网络）→ 用合成重度图扩充训练 → TSTR/TRTR 验收（重度类 Recall/F1/平衡准确率）。
**验收**：合成重度图显著提升分类器对重度类的性能。

## 门控原则

- **不擅自扩展**：若某方法意外高分/结果异常，停下与用户确认，不自己扩大范围。
- **先冒烟后生成**：任何脚本先 `--num_images 5` 验证，再跑标准 60 张（2026-08-18 新规）。
- **复制检测必过**：任何生成方法不过三件套质检不进入评估。
