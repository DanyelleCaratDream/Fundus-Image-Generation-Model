# 综合洞察：从三路文献调研中学到了什么、接下来怎么做

> ⭐ 本报告的核心交付。前 01/02/03 是"文献清单"，本篇是"读后的思考"——经验、灵感、为什么这些方法有用、后续行动。
> 更新日期：2026-08-03

---

## 0. 一句话总结

**纯传统 ML 直接生成不可行，但"传统 ML 组合管线"可行且有眼底先例。** 我们不必用传统 ML 去复刻深度生成，而是用它做**深度模型做不到的事**：显式控制结构（血管/视盘布局）与病灶（种类/密度/位置）的"新组合"。这正好匹配老师 Bug 2 的意图，也给论文一个独特的贡献点。

---

## 1. 经验：传统 ML 生成为什么"难"（学到了什么）

读 18 法文献，最深的一条规律：

> **传统 ML 生成器的能力边界，由它"假设的数据分布形状"决定。**

| 方法 | 假设的分布 | 为什么在眼底图上失败/受限 |
|:--|:--|:--|
| PCA/PPCA/FA | 高斯线性子空间 | 眼底图是强非高斯（黑背景/亮视盘/暗病灶）+ 强结构（血管走向）。线性假设把一切拉向"平均脸"，病灶被平均掉 |
| GMM（像素级） | 高斯混合 | 像素独立假设，无空间关系 → 采样出噪声；维度灾难 |
| KDE/FRAME/MRF | 平滑经验分布 / 局部邻域 | 保纹理不保全局，无法维持血管走向/视盘位置/病灶布局 |
| 补丁法（quilting/字典） | **不假设全局分布，直接重排真实纹理块** | 反而是唯一能保"相似"的——因为它不压缩信息，只是重组 |

**经验一**：参数化模型（PCA/GMM/密度）必败于"非高斯 + 强结构"的医学图；**非参数补丁法胜出**，因为"重排真实块"天然保留纹理真实性，只是缺全局结构。

**经验二**：补丁法缺的"全局结构"，可以由**另一层传统方法补**（血管骨架生成 + 病灶布局规划）——这就是"组合管线"能工作的原因。单一方法不行，组合可以。

## 2. 灵感：四个值得做的方向（含为什么有用）

### 灵感 A：泊松病变重排（文献基础：强）
- **做法**：330 张全是严重 DR = 一座病变模板库。从图 A 取渗出簇、图 B 取出血斑、图 C 取微动脉瘤，用泊松编辑无缝贴到图 D 上，产出"新病变组合"的严重 DR 图。
- **为什么有用**（机制）：泊松编辑只保留**插入区域的梯度**，用背景的边界条件求解，所以贴上去的病灶与宿主图无缝融合、无接缝伪影。它不动宿主图的其他内容，只"多"了一处病灶——这是经典的"相似但不相同"。
- **文献**：Pérez 2003（方法）+ Yu 2021 BOE（眼底专版，DR 筛查优于过采样/裁剪/旋转）[02 篇 §3C]。

### 灵感 B：Retinex 光照交换（文献基础：强）
- **做法**：把每张图分解为 光照 L × 反射 R，跨图交换 L、保留各自 R，重乘出"光照不同、结构相同"的新图。
- **为什么有用**：Retinex 把"颜色/照度"和"结构/内容"解耦。反射 R 承载解剖结构（血管/视盘/病灶），光照 L 承载采集时的明暗/色温。交换 L 只改变"看起来的调子"，诊断语义几乎不变 → 安全的多样性放大器。
- **文献**：Zhang 2022 CBM（眼底专版，分割提升 9.6% Dice）[02 篇 §3F]。

### 灵感 C：血管骨架 + 补丁纹理拼布管线（文献基础：强，结构层）
- **做法**：用传统方法（ASM/Bonaldi 或过程化 CCO/DLA）生成全新血管骨架，从真实图无病变区采纹理补丁沿骨架拼布，inpainting 补缝。
- **为什么有用**：结构层决定"不重复"（骨架是全新的），纹理层决定"相似"（补丁来自真实图）。Fiorini 2014 / Magnusson 2021 已在眼底验证并提升分割 SOTA。
- **文献**：[02 篇 §1.1-1.3]。

### 灵感 D：COCA 修正的 PCA 潜空间（文献基础：中，最"科研向"）
- **做法**：PCA 潜空间里做插值/采样时，用高斯 copula 把非高斯边缘分布修正回来（rank 变换 → PCA → 按经验边缘逆变换）。
- **为什么有用**：解决"线性模型生成非高斯伪影"这个根源问题。眼底图边缘分布明显非高斯，COCA 是传统方法里最有"方法论价值"的改进点。
- **文献**：Egger 2016 COCA [01 篇 §6.1]。

> **优先级**：A ≈ B > C > D。A/B 有眼底专版、不重训模型、直接产出"相似但不相同"；C 结构层价值大但工程量高；D 最科研向但改造量大。

## 3. 审视：生成 vs 增广，C2 的价值到底在哪

第三路文献给了我们一个必须诚实面对的结论：

> **经典增广（旋转/mixup）对分类器的判别力提升，普遍不输甚至超过 GAN/扩散生成图扩充。**

这要求我们把 C2 的价值主张讲对：

- ❌ 不能说"传统 ML 生成比增广强"——文献不支持。
- ✅ 应该说的是：**传统 ML 组合能产出"经典增广做不到的新病灶组合"**。旋转/mixup 不产生新的病灶布局，泊松病变重排能。C2 的价值锚定在"新组合"而非"更强的判别力"。
- ✅ 另一层价值是**方法论对照**：证明"为什么深度生成/组合管线是必要的"（纯传统 ML 基线失败），回应老师 Bug 2 时给出完整的对比证据链。

**对论文的含义**：C2 章节的贡献点不是"我们做出了好图"，而是 **(1) 系统盘点了传统 ML 生成方法在小样本眼底上的边界；(2) 给出了"结构+纹理+融合"的可组合管线范式；(3) 用统一的评估体系横向对比了传统基线 vs 深度方法。**

## 4. 教训：记忆/复制风险必须内置（330 张小样本）

- **学到的**：330 张对生成器处于"记忆高风险区"（GLO 在 128 张就开始记忆；复制率随规模指数衰减）。补丁法有"局部复制"陷阱（拼布可见重复块、病变直贴=复制原图局部）。
- **怎么防**：任何生成方法（包括传统组合）跑完必须做**复制检测三件套**：
  1. 生成图 ↔ 330 训练图的最近邻 SSIM/LPIPS 距离分布
  2. 全图级复制率（Feng 2021 方法）
  3. 补丁级重复块占比
- **为什么必须内置**：C2 的承诺是"相似但不相同"，如果悄悄复制了训练图，评估体系里的"记忆检测"维度会直接暴露，结论失效。

---

## 5. 教训：评估纪律（增广文献的提醒）

- **患者级划分**：330 张若含同一患者双眼底，图像级评估会系统性高估（文献报高估 8-12pp）。下游分类验证必须患者级。
- **simplicity bias**：模型会利用"真实 vs 合成"的统计差异——合成图质量再好，混入训练也可能让分类器学"伪影"。需要质量筛选 + 组合使用。
- **视觉保真不预测下游有用性**：FID/KID 低 ≠ 分类器提升大。C2 的图最终用下游分类器（Phase D TSTR/TRTR）验收，而不是只看生成指标。

## 6. 后续怎么做（落地路线）

**第一阶段（确定性基线，先跑）**：PCA / GMM / 补丁拼接 3 个传统基线，各 300 张 → 评估 → 打分。预期得分远低于扩散模型，作为"纯传统 ML 无生成价值"的否定性结论底。

**第二阶段（高价值组合，文献最强）**：泊松病变重排（灵感 A）+ Retinex 光照交换（灵感 B），各 300 张 → 评估 → 打分。预期"相似但不相同"（复制率低、病灶保留好），是 C2 的正面亮点。

**第三阶段（可选）**：血管骨架 + 纹理拼布管线（灵感 C），工程量高，视一/二阶段结果再定。

**贯穿**：复制检测三件套 + 评估体系（`eval_data/` JSON → score_scheme → plot_metrics）。
