## 三句话结论（先看这个）

1. **纯传统 ML 直接生成不可行**：PCA/GMM/像素密度这类"隐空间采样"方法在非高斯、强结构的眼底图上必然过平滑、丢病灶——它们是**确定性基线**，用来证明"为什么必须上深度/组合方法"。
2. **但"组合"可行且有先例**：非深度眼底合成是深度时代前的主流，范式 = **血管骨架/结构生成 + 纹理拼布两步走**（Fiorini 2014、Bonaldi 2016、Magnusson 2021 已在真实眼底图上验证并提升下游分割 SOTA）。两个最值得做的组合：**泊松病变重排**（Yu 2021）和 **Retinex 光照交换**（Zhang 2022）。
3. **生成 vs 增广要摆正位置**：文献显示 GAN/扩散生成图扩充分类器，判别力普遍不优于经典增广（旋转/mixup）。C2 的价值主张应锚定在"**经典增广做不到的新病灶组合**"，而不是"比增广强"。
