## 0. 答辩总策略（先背这一段）

**一句话主张**：我们没有声称"传统 ML 生成比深度生成强"，而是系统证明了——纯传统 ML 直接生成在 330 张严重 DR 图上必然失败，但"传统 ML 组合管线"（泊松病变重排 + Retinex 光照交换）能产出深度无条件生成器难以显式控制的新病灶组合，作为数据扩充有补充价值。

**三层防线**：
1. **方法论对照**（打底）：三个基线（PCA/GMM/补丁）的系统失败，本身就是"为什么需要深度生成或组合管线"的证据链，回应老师 Bug 2 的"方法不限于深度学习"。
2. **组合价值**（正面）：泊松造新病灶组合（复制率 0.3%、C2ST 0.804 全场第 2 低）、Retinex 做安全多样化（C2ST 0.744 全场最低、复制率 0%）。做的是经典增广（旋转/mixup）和深度无条件生成器都做不到的事。
3. **诚实的边界**（兜底）：高分部分源于底图复用，人眼评分待补，Phase D 下游分类验证未做。这些我们主动写在报告里，答辩时不设防。

**最容易死的三个位置**（提前自曝，比被问出来强）：
- min-max 相对分：模型一变分数全变（film 70.8→45.2）。应对：报告已标"完成时 X"迁移，答辩主动说"相对分，跨版本不可直接比，以同一版 _scores.json 为准"。
- 泊松/Retinex 高分部分是"真实像素的平凡胜利"。应对：主动标注，并且点出体系其实在 D6 记忆维度惩罚了它们（poisson D6=0.00）。
- Retinex 60 张 vs 泊松 300 张样本量不一致。应对：承认是执行纪律（2026-08-18 新规 60 张），Phase D 前补跑对齐。

## 1. 选题与动机

### Q1-1 "深度生成已经很成熟了，为什么还要做传统 ML？是不是开倒车？"
不是开倒车，是两个正交的问题。

第一，这是老师 Bug 2 的直接要求：方法不限于深度学习。传统 ML 在 330 张小样本上能不能直接生成、能到什么程度，这个"边界问题"文献没有系统回答过，我们把它跑透了。

第二，传统 ML 组合有一个深度方法没有的显式控制能力。泊松病变重排可以直接控制"把这张图的病灶搬到那张图"，Retinex 可以直接控制"只换光照不换结构"。深度无条件生成器做不到这种控制——你没法告诉扩散模型"只把光照换成另一张图的"。这种"可显式控制的组合"正好是数据扩充要的东西。

第三，结果是诚实的：纯传统 ML 直接生成确实不行（三个基线全败），但这恰恰证明了深度生成和组合管线的必要性。我们给论文提供的是完整的"为什么需要深度方法"的对比证据链，而不是又一个生成器。

### Q1-2 "你的贡献到底是什么？不是'做了几张图'吧？"
三层贡献，按重要程度：
1. **方法论对照**：18 种传统 ML 生成方法，330 张重度眼底图上系统验证"分布假设决定能力边界"——参数化必败、非参数保相似缺结构。这回应了"传统 ML 在小样本医学图上到底行不行"。
2. **组合管线范式**：证明了"结构+纹理+融合"的可组合路线（单一方法不行，组合可以），泊松和 Retinex 是这条路的两个落地实例。
3. **统一评估体系**：把传统 ML 基线和深度方法放进同一套六维门控评估，横向可比。这个体系本身（含踩过的坑，比如补丁伪高分）也是方法学贡献。

我们明确不主张"做出了比深度更好的图"。主张的是"找到了传统 ML 的合理生态位"。

### Q1-3 "文献说经典增广（旋转/mixup）对分类器提升不输甚至超过生成图，你为什么还做生成？"
正因为文献这么说，所以我们的价值主张必须锚定在增广做不到的事上。旋转、裁剪、mixup 只在"已有的那张图"上做手脚，不产生新的病灶布局。泊松病变重排把两张图的病灶重新组合，产出"这张图原来没有的病灶组合"，这是经典增广做不到的。如果我们的目标是"把分类器提高 1 个点"，那增广就够了，不需要生成。但"生成新病灶组合、扩充重度 DR 这一稀有类的多样性"是增广的盲区。

一句话：我们不争"生成比增广强"，我们做"增广做不了的多样性"。

### Q1-4 "330 张样本，够吗？为什么不用公开数据集？"
够不够要看用途，而且 330 张正是问题的一部分，不是我们偷懒。

对"生成器训练"，330 张是极小样本，这正是记忆/复制风险高的原因（文献里 GLO 在 128 张就开始记忆训练集）。我们没有回避，而是把复制检测三件套内置进评估，所有方法跑完必查。

对"评估对照"，330 张真实图做分布对比（FID/C2ST/病灶保留）是够的，统计量稳定。

为什么不用公开数据集：这个项目的真实约束是老师提供的 330 张 KW-IV 严重 DR 图，就是要在这个特定小样本、特定重度的场景下做扩充。公开数据集（如 EyePACS、IDRiD）的分级、成像、采集条件都不同，混进来会破坏"同一份数据、同一口径"的对比纪律。深度方法（Phase A/B）和传统 ML（Phase C）用同一份数据，横向对比才成立。这是设计选择，不是疏忽。

### Q1-5 "KW-IV 级全是重度，这是不是让任务变简单了？"
确实变简单了一部分，但我们利用了它，也付出了代价。

简单的一面：重度图到处是病灶，泊松随机贴片不需要病灶检测，随便搬一块就是病灶样内容。这是工程上的红利，报告里明说了"330 张全是重度 = 自带病变模板库"。

代价的一面：数据分布高度非高斯、高度集中，参数化方法（PCA/GMM）在这上面死得更快更彻底。补丁拼接这类"保相似"的方法更容易刷高病灶保留，所以评估必须靠 C2ST 和记忆检测来把"搬运派"和"生成派"分开。我们的方法选择、评估设计都围绕这个前提展开，答辩时要把"重度"既当便利也当约束来讲。

## 2. 方法与原理

### Q2-1 "PCA 为什么必败？'保留 96% 方差'砍掉的到底是什么？"
PCA 是线性子空间方法，把 330 张图当 330 个点，在 49152 维空间里找 64 个按方差排序的正交方向。生成图 = 这 64 个方向的加权和。

砍掉 4% 方差，砍掉的是高频结构：病灶边缘、细血管分叉这类"锐利但占比小的差异"。96% 方差是被大片平滑区域（黑背景、视网膜渐变、大致血管走向）占走的。所以 PCA 输出的东西"平均脸"感极强，病灶被稀释成一片糊。实测 FID 297.1 全组最差、1-NN 1.000 完美可分、IS 1.58 多样性几乎为零。

更根本的：它不是"训不够"，是机制性失败。线性假设把一切拉向均值，病灶作为强非高斯、强离群的结构，天然不在线性子空间里。这不是调参能救的。

64 维怎么定的：保留 96% 方差对应的主成分数，是标准做法（保留 90-99% 方差取整数维）。换 128 维也只是从 11.9 变成 12 分，天花板在那。

### Q2-2 "GMM 为什么过平滑？EM 为什么 2 次就收敛？"
GMM 用 16 个多维高斯团去覆盖 PCA 压缩后的 64 维点云。生成 = 随机挑一个团、从团里采样。高斯分布的形状是光滑钟形，采样永远落在中心附近，表达不了尖的病灶边缘。这是"圆表达不了尖"，机制性限制。

EM 2 次收敛是有实证的：给了 10/100/1000 次迭代上限，BIC 在 2 次后不变。原因是这 330 张重度图的分布太集中（全是重度的近亲），16 个高斯团很快就能把团心定准，后续迭代只是微调团形，BIC 不再下降。这反过来印证了"重度图分布高度集中"——多模态优势（GMM 比 PCA 强的理论点）在这么集中的数据上发挥不出来。

### Q2-3 "补丁拼接连模型都没有，算'生成'吗？"
严格说不是生成，是无参数重排。我们没有虚报它，方法章标题明确写"无模型纯重排"。

它的存在价值是当"基线上限参考"：代表"完全不做结构、纯搬真实像素"能到什么程度。结果它病灶/血管/颜色三维全高分（像素是真的），但 C2ST 1.000 被小 CNN 一眼识破，总分只有 31.0。这个结果本身证明了"保相似靠真实像素、但缺结构必然被识破"，正好引出组合管线。它是否定性证据，不是我们要吹的方法。

### Q2-4 "泊松病变重排为什么有效？为什么不需要病灶检测？"
机制：泊松编辑不在像素值上直接做，而是操作梯度（相邻像素差值）。它把供体病灶区域的梯度整体搬过来，再要求拼接边界处梯度跟宿主图连续，解一个线性方程（泊松方程）。梯度连续 = 颜色过渡自然 = 接缝肉眼不可见。直接 copy-paste 会在边界留一圈色差，泊松专门消掉这个。

为什么不需要病灶检测：330 张全是重度图，任何局部区域都含病灶/血管纹理，随机椭圆贴片簇（半径 60-150px @512，1-3 簇重叠椭圆）搬来的就是病灶样内容。我们试过病灶检测（局部对比度启发式），验证失败：启发式无标定、无法自证，排除血管 mask 后与原始图不对齐（量化验证过）。与其用不可靠的检测，不如诚实承认"重度图处处是病灶"。这是工程取舍，报告里如实记录了检测尝试的失败。

风险：随机贴片可能贴到供体的视盘，产生"多视盘"伪影。靠人工蒙太奇抽查把关。

### Q2-5 "Retinex 光照/反射怎么分？大核 41 是怎么定的？"
分解：log(图) = log(光照) + log(反射)。光照 = log 域高斯低通（大核），反射 = 原图减光照。在 log 域做是因为"光照乘反射"取对数变加法，分离干净。光照承载采集时的明暗/色温，反射承载诊断语义（血管/视盘/病灶）。

交换公式：新图 = R_A · L_A^(1-α) · L_B^α。取 log 就是 (1-α)·logL_A + α·logL_B + logR_A。α=0 完美还原底图 A（实测 max err 0），α=1 纯交换，α∈[0.6,0.9] 每张随机。

大核 41 是被"复制率"这个门控逼出来的，不是拍脑袋：小核 k25 会把纹理混进光照，交换光照时携带结构 → 复制率飙到 27%；k41 光照只剩平滑渐变、纹理全在反射里 → 交换后复制率归零。冒烟测试直接测出来的。核越大光照越纯，41px @512 对应视网膜直径约 1/12，足够大。

### Q2-6 "Retinex v0 的公式错误，具体错在哪？"
v0 写成 new = R_A · L_B^α，只乘了供体光照，丢掉了 L_A^(1-α) 这一项。后果：α 把光照幅度压缩了——90^0.8≈36 而不是 90，输出近全黑（暗像素占 97-99%）；而且 α=0 时不还原底图（因为 L_A 那项根本不存在），连"半交换"的语义都没有。

改成 log 域插值后：α=0 完美还原（误差 0）、α=0.8 亮度 144 vs 底图 150。这个事故的价值：它暴露了"指数式公式要验证边界条件"，也让我们建立了冒烟测试（生成前先出 5 张看亮度/结构）。

### Q2-7 "泊松和 Retinex 都'复用底图'，这算不算作弊？"
不算作弊，算设计定位，但我们如实标注了，答辩要点破这个区别。

它们的目标本来就不是"从噪声造全新解剖"，而是"保留宿主图解剖 + 引入新变化"。泊松引入新病灶组合（位置/数量改变），Retinex 引入新光照。这是"相似但不相同"的扩增，不是"原创生成"。所以病灶/血管/颜色三维的高分是"真实像素的平凡胜利"——体系没有掩盖这一点，D6 记忆维度里 poisson 0.00、retinex 0.099，都是"最接近真实集"的代价分。

如果答辩者质疑"这不算生成"，正确回应：对，它不算生成，它是有明确边界的扩增方法。论文里把"生成"和"扩增/组合"分开定义，这是我们的主动定位，不是漏洞。

## 3. 评估体系

### Q3-1 "综合评分是 min-max 相对分，模型一变分数全变，这科学吗？"
科学，但有边界，我们主动声明了边界。

设计意图：min-max 是"组内相对排名"，不是绝对质量分。我们没有人量级的人工标注基准（人工分只有 6 个深度模型），min-max 是纯自动、零人工、可复现的方案，能把 11 个模型放进一个标尺。

代价：引入新模型会让旧分整体平移——film_l1lpips 从 70.8→47.4→45.2，poisson 从 87.5→80.8。这不是"分数错了"，是"相对位置变了"。处理方式：报告每个分数都标了"完成时 X"，跨版本对比以同一版 _scores.json 为准。论文阶段建议报"绝对指标原值表（FID/KID/C2ST）+ 相对分"双轨，只报总分会被打。

### Q3-2 "六维权重怎么来的？D1 病灶 0.30 为什么最高？"
三个依据叠加：
1. **任务核心**：KW-IV 任务里，出血/渗出是分类器识别"最重级"的关键信号，病灶保留权重最高（0.30）符合任务定义。
2. **实证校准**：候选指标跟 6 个深度模型人工分做 Spearman 相关，C2ST（ρ=-0.771）和 KID（ρ=-0.886）最贴人工，所以 D2 抗识破权重次高（0.25）。这是"指标去留"的数据依据，不是纯拍脑袋。
3. **权重是公开公式**：formula_version v1 写死在 eval/score_scheme.py，每个指标的维内权重可复现。

诚实承认：任何多指标加权都有权重选择自由度。缓解手段是公开公式 + 提供未门控原始分对照。可以补一个"权重敏感性分析"（扰动权重看排序稳不稳）——这是答辩加分项，应该补。

### Q3-3 "C2ST 是什么？伪高分事件到底怎么回事？"
C2ST（Classifier Two-Sample Test）：训练一个小 CNN 去区分真实图 vs 生成图，5 折交叉验证，输出 AUC。AUC 越接近 1.0 越容易被识破，越接近 0.5 越分不出来（越好）。它是"像不像真实"的最强代理。

伪高分事件是评估体系的真实教训：早期执行计划对"传统 ML 无条件图跳过 C2ST"，理由是当时认为 C2ST 只适合生成方法。后果是补丁拼接打出 62.9 分逼近当年深度最佳 70.9——因为补丁的像素是真的，病灶/血管/颜色三维必然高分，而 D2 里权重 0.40 的 C2ST 缺了，口径不均。补跑 C2ST 后 patch 回落到 31.0，跟深度模型同口径。

这个事件的价值：它暴露了评估体系的盲区——凡是用真实像素的方法，病灶/血管/颜色三维必然高分，所以跨"真实重排 vs 生成"对比时 C2ST 不是可选项是必选项。执行计划改成了"C2ST 必跑"，这个事件写进了报告 6.4 和 2.7，作为体系改进的实证。

### Q3-4 "病灶保留率用颜色阈值，没有真值 mask，怎么证明测的是病灶？"
测的不是病灶本身，是"病灶样内容"的代理，我们如实声明了。

阈值在真实图上标定：出血 = R-G>0.04 且 R-B>0.04 且 R<0.42 的暗红；渗出 = 三通道都亮（min>0.42、mean>0.48）。为什么能当代理：KW-IV 重度图的病灶区域在颜色上高度可区分（暗红出血、亮黄渗出），在"每图像面积占比分布"层面（Wasserstein 距离 + 保留率）足够区分"有没有病灶样内容"。它不声称测每块病灶的边界，只测面积占比分布。

局限：分不清"真病灶"和"像病灶的颜色块"。缓解：病灶 + 血管（Frangi）+ C2ST + 人工抽查多指标三角验证，且最终判据是 Phase D 下游分类器。文献里无标注场景下病灶评估普遍用颜色/强度代理，这是社区现状，论文里必须声明"代理"二字。

### Q3-5 "记忆检测为什么用 NN-SSIM >0.85？0.85 哪来的？"
0.85 是工程阈值，来源两条：
1. 文献常用：Feng et al. 2021（ICCV）记忆检测方法，SSIM 0.85 作为"接近复制"的判别线是领域惯例。
2. 经验校准：真实眼底图自身的近邻 SSIM 约 0.55-0.6 量级，0.85 明显高于真实集自相似，划在这里能抓住"复制训练图"的尾部而不误伤正常样本。

但要诚实：0.85 不是数学推导出来的，是工程经验值。我们的复制率 0% 不是"0.85 以上一个都没有"，而是"生成后过滤主动拒绝 >0.85 的样本"（Retinex 方案 3）或"重排增强让 >0.85 的样本数降到 0.3%"（泊松）。报告里区分了这两种 0%。

### Q3-6 "门控 R=D2 是怎么回事？会不会过度惩罚？"
门控机制：R = D2 抗识破得分（clamp 0-1），乘到 D1/D4/D5 三个"容易高分"的维度上。代码里 GATED_DIMS = {D1, D4, D5}，D2/D3/D6 不乘。

设计动机：病灶保留（D1）、血管（D4）、颜色（D5）都可以被"糊图"或"搬真实像素"刷出高分，所以用 D2（像不像真实）去闸住它们。PCA 就是被门控杀死的典型：D2=0.076，D1 0.684×0.076≈0.05，血管、颜色全被压下去，总分 11.9。没有门控的话 PCA 能靠 D5 颜色 0.937 拿到明显更高的分——那才是不公平。

会不会过度惩罚：会，这是设计取舍。一个"抗识破略差但病灶极真"的方法会被连坐。缓解：报告同时输出未门控原始分（score_scheme --no-gate），两个数都公开，让审查者自己判断。

### Q3-7 "为什么 poisson 80.8 > 深度最佳 45.2？你的体系是不是偏袒'搬运派'？"
这问题要拆成三层答：
1. **分数的性质**：min-max 相对分 = 组内排名，不是绝对质量。poisson 是 11 个模型里唯一"病灶/血管/颜色全部继承真实像素"的方法，在这三维天然接近满分（D4/D5=1.0）。这是相对分的设计使然。
2. **体系没放过它**：D6 记忆维度 poisson=0.00（全场最接近真实集），这个维度就是在"惩罚"底图复用。体系没有偏袒，反而是把"真实重排 vs 真正生成"放到同一标尺上让差异显性化。
3. **为什么它确实配高分**：D2 抗识破 0.87 是"真"的高——C2ST 0.804（全场第 2 低），说明它确实难被识破；D1 病灶 0.969 是它方法论承诺的核心（搬运真实病灶）。门控 R=D2 高 → D1/D4/D5 不被压。所以高分 = 真实像素 + 难识破 + 病灶保留好，三者共同作用，不是单项偏袒。

结论：正确的批评应该是"病灶/血管/颜色三维对搬运派区分度低"，而不是"体系造假"。报告里明确写了"高分部分源于底图复用"，答辩主动讲比被揪出来好。

### Q3-8 "1-NN poisson=0.694，retinex=0.951，为什么差这么多？"
1-NN（真假混合最近邻）越接近 0.5 越分不开（越好）。这个差异是真实、可解释的：
- poisson 改了病灶位置/数量，破坏了底图的"结构指纹"，所以大量生成图跟真实图混在一起分不出 → 0.694（接近真实水平）。
- retinex 只改光照不改结构，它的最近邻就是底图本身（特征空间里结构+光照最像的就是底图），所以容易被区分 → 0.951。

这恰好印证了 Retinex 的致命缺点：多样性主要在光照层面，结构层面的多样性有限。1-NN 把这一点直接暴露出来了。答辩如果被问"retinex 为什么 1-NN 差"，正确回应是承认并把它引到"这是它的已知边界"。

## 4. 结果解读

### Q4-1 "泊松复制率 0.3%、Retinex 0%，怎么保证的？过滤是不是有副作用？"
两条路径，机制不同：
- 泊松：v1 版本贴片太小（只改 1-6% 像素），mem_ssim 0.942/复制率 96.7% 触发门控停线。v6 增强重排（10 贴片 + 全局旋转 ±15° + 色彩 ±18%）后归零到 0.3%。靠的是"破坏底图指纹"。
- Retinex：方案 3 生成后过滤。每张与 330 张真实图算 NN-SSIM（pytorch_msssim，和评估同口径），>0.85 重采样，最多 20 次。60 张实测 1 张 0.891 被滤掉，中位 NN-SSIM 0.616 基本不动，只剔尾部。

副作用是真实的：Retinex 的过滤本质是"选择偏差"——主动拒绝离真实集最近的样本，等于把生成分布尾部截断了。对 Retinex 影响小（只剔 1/60），但严格说不是"生成的图都离真实远"，是"我们不让近复制的样本流出"。报告如实标注了这是质量控制。答辩要主动说"过滤改变分布，我们量化过影响很小，但存在"。

### Q4-2 "泊松 300 张、Retinex 60 张，样本量不一致怎么比？"
这是执行纪律导致的，承认，但给修复方案。

2026-08-18 定了"新方法 60 张"的样本量新规（评估成本 + 门控要求），泊松在规则生效前跑（300 张），Retinex 在规则生效后跑（60 张）。评估指标对样本量敏感：FID/KID 小样本有偏，C2ST 每次 5 折训练的方差也不同。六维 min-max 相对化缓解了一部分，但不消除。

严谨做法：Phase D 前把 Retinex 补跑到 300 张或泊松降采到 60 张重评，保证同口径。这是明确的待办，不是掩盖。答辩时主动说比被问出来强。

### Q4-3 "为什么 128×128？这么低分辨率能诊断 DR 吗？"
两个层面：
1. 这是与深度方法对齐的口径。Phase A/B 的 6 个深度模型全部定在 128×128（训练成本约束），传统 ML 要和它们同标尺对比，必须同一分辨率。
2. 细节：泊松/Retinex 的"搬运/交换"实际在 512 工作分辨率做，只是输出降到 128 来对比评估。所以组合方法的核心操作没有在低分辨率损失。

局限性要承认：128×128 对微动脉瘤这类细微病灶会丢失，不能用于临床诊断。本项目的定位是"分类器训练集扩充"，不是临床工具。论文里要写清这个边界，不然答辩会被"分辨率"打死。

### Q4-4 "为什么没有患者级划分？330 张里如果有同一患者的双眼怎么办？"
现状是：评估全部是"图像级"（生成图 vs 330 张真实图的分布对比），没有训练/测试划分，所以患者级泄露对"生成质量评估"的影响有限——它不是分类器训练，不存在"测试泄漏抬高精度"。

真正受影响的是 Phase D 下游分类验证。文献明确报过：同患者双眼做图像级划分会让 TSTR/TRTR 系统性高估 8-12pp。所以 Phase D 必须患者级划分，这是写进报告 8.4 局限和 06-Records 的已知待办。Phase D 前要跟老师确认 330 张的患者元数据，或做双眼相似度筛查。

这是诚实清单的一部分，答辩主动说"我们还没拿到患者元数据"比被问倒好。

### Q4-5 "Retinex 渗出保留率 0.44，比真实少了 56%，为什么报告里没把它当致命伤？"
它是已知弱项，报告写了"渗出偏低"，但没把它当致命伤有原因：
1. D1 是复合维度：渗出保留率只占 D1 的 0.25 权重，D1 还有出血 Wass/渗出 Wass/出血保留率，retinex 的出血保留 1.06 接近完美，整体 D1 0.939。
2. 机制解释：光照交换改变亮度/色温，渗出阈值（min RGB >0.42 的亮色）可能匹配不上，渗出在数值上"看不见了"，不一定是解剖上消失了。这是光照变换对颜色敏感型病灶的代理性副作用。
3. 它暴露了 Retinex 的边界：只交换光照，对亮度敏感型病灶保留有影响。这个边界应该写进局限，答辩时主动讲。

### Q4-6 "你说'相似但不相同'，怎么量化？相似多少算相似？"
工程定义，三层：
1. 相似 = 最近邻 SSIM/LPIPS 与真实集自相似同量级。Retinex 中位 NN-SSIM 0.616，真实集自相似约 0.55-0.6。
2. 不相同 = 接近复制（NN-SSIM>0.85）被拒绝 + C2ST 不能到 1.0。泊松 C2ST 0.804、Retinex 0.744，都没到"一眼识破"。
3. 结构性证据（Retinex 特有）：Laplacian 高频与底图相关 0.52-0.84（结构语义跟随底图），整图灰度与供体相关（光照包络跟随供体）——结构不变、光照变，这是"相似但不相同"的定量行为。

诚实说：这是一个区间定义（NN-SSIM 落在 0.5-0.85 附近），不是硬数学边界。0.85 是工程阈值。论文里声明"这是工程定义"。

### Q4-7 "没有人工评分，凭什么说有效？"
我们没说要凭人工分证明有效。自动分不依赖人工分（人工分只用于校准哪些指标保留，见 score_scheme 的 calibrate）。ML 方法的人眼评分标"待人工评估"，没有虚报。

当前的主张边界：只主张"指标层面的高实用性分 + 复制率可控 + 抗识破好"，不主张"临床有效"。临床/分类器有效性是 Phase D 的事（TSTR/TRTR）。主动说"我们知道缺人工分，Phase D 会用下游分类器补上"比藏着强。

### Q4-8 "Film 扩散的 FID 178.8 还不如补丁的 159.2？你的评估是不是乱了？"
FID 单指标不能这么横着读，这正是我们做"两层评估 + 六维门控"的原因。
- 补丁 FID 低是因为像素是真的（分布贴近真实集），但 C2ST 1.000 说明它被一眼识破。FID 对"结构合理性"不敏感，对"像不像真实分布"敏感，而真实像素拼接天然骗过 FID。
- film 扩散是"生成"，FID 178.8 反映它还有真实感差距，但它 recall 0.442、lpips_nn 0.663 表现好，C2ST 和人工分（87.5）都认可它。
- 单个指标会被"搬运派"骗，所以要用 C2ST（抗识破）+ 记忆检测（复制）+ 病灶/血管（医学语义）一起看。这正是我们评估体系的设计动机，也是伪高分事件教我们的。

补一个反方向的事实：film_l1lpips 是深度最佳（人工分 87.5），但它的渗出保留率 13.7——生成图里"亮黄白区"比真实多 12 倍，严重过生成。相比之下泊松 0.97、Retinex 0.44。这说明"深度模型 FID 一般但人工分高"和"搬运派指标好看但被识破"是两种互补的偏斜，单指标（不管 FID 还是病灶保留）都会被骗，这就是两层评估的意义。

## 5. 严谨性与局限

### Q5-1 "BRISQUE 是自然图像上训练的，用它测眼底图合适吗？"
不合适做绝对判断，我们只当参考。报告里写的是"真实眼底 = 3.69，仅参考"。

用它有两个理由：一是它便宜、无参考，能抓"模糊/噪声/伪影"这类通用质量退化；二是泊松 3.60、Retinex 3.70 都逼近真实 3.69，PCA 16.1/GMM 20.0 明显差，说明它对"严重失真 vs 基本正常"还是有区分力的。

局限要讲清：BRISQUE 没学过眼底图的纹理分布，它的"正常"概念不一定是眼底的"正常"。论文里把它降级为参考指标，不参与评分（score_scheme 里 brisque_fake 是"参考"不进计分）。

### Q5-2 "可复现性怎么保证？随机种子、参数都公开了吗？"
公开了。seed=42 全程固定，每个方法的超参数都在 06-Records 的 EX-XXX 节和生成脚本默认值里：PCA 64 维、GMM 16 团、补丁 64×64 四块、泊松 max_patches=10/patch_radius=100/rot=15/color_jit=0.18、Retinex kernel=41/α∈[0.6,0.9]/mem_thr=0.85/max_retry=20。评估脚本 CLI 也在 06-Records 里。

一个诚实的点：C2ST 有随机性（5 折交叉验证 + 随机初始化），但 seed 固定可复现；min-max 相对分意味着分数依赖模型库快照，复现时要锁死 _scores.json 版本。

### Q5-3 "你的病灶/血管评估全是'代理'，没有真值，这个体系可信吗？"
可信的前提是"我们说了它是代理"。三个层级：
1. 病灶：颜色阈值代理（暗红出血/亮黄渗出），无 mask 下的社区现状。
2. 血管：Frangi 滤波血管度（无监督），Vessel Dice 只有条件模型能用（对生成时用的输入 mask）。
3. 这些代理都不声称"解剖级准确"，只声称"在分布统计层面能区分有没有病灶样内容/血管样结构"。

真正可信的判据在 Phase D：下游分类器用这些图扩充训练，看分类性能是否提升。生成指标是"预筛"，下游验证是"终判"。答辩时主动把这条链路讲清楚，比被逼问"代理怎么可信"强。

### Q5-4 "为什么补丁拼接早期 62.9、后来 31.0？分数还能'修'？"
分数没有修，是口径补齐了。62.9 是在"跳过 C2ST"的错误口径下算的；补跑 C2ST 后重新打分 = 31.0。这不是调分，是把缺失的 0.40 权重指标补上，让传统 ML 和深度模型同口径。

这个事件我们应该主动讲，因为它同时是坏事（评估纪律有过疏漏）和好事（暴露了评分体系的盲区，现在 C2ST 必跑写进执行计划）。

### Q5-5 "组合方法的'高分'是不是被底图复用喂出来的？那结论还成立吗？"
结论依然成立，但要说清"高分"的性质。
- 泊松/Retinex 的高分是"作为扩增样本的实用性"高分：病灶保留好、抗识破好、复制率低、BRISQUE 接近真实。这些正是"数据扩充"要的属性。
- 它不是"作为生成器的原创性"高分：结构继承底图，D6 记忆维度 0.00/0.099 已经暴露。
- 所以结论措辞必须是"组合方法作为扩增有价值"，不能说"组合方法生成了新解剖"。论文里这两个说法是严格区分的。

## 6. 最难的三问（预演：考官连问三次"为什么"）

### Q6-1 考官："你的评分体系是相对分，那 80.8 和 72.5 到底有没有意义？"
第一次答：它是组内排名的意义——在 11 个模型里，泊松/Retinex 作为扩增候选排在最前面，这个排序是稳定的（跨维度差异远大于权重扰动）。

考官再问："那我换个模型进来，80.8 变 70，你怎么办？"
第二次答：相对分本来就会平移，所以论文报绝对指标原值表（FID/KID/C2ST/病灶保留）作为主证据，总分只做组内排序参考。80.8 不是"绝对质量"，是"当前库内第 1"。

考官再问："所以结论其实依赖你选了什么模型进库？"
第三次答：不依赖。核心结论"组合方法作为扩增优于三个基线和深度无条件方法"靠的是绝对指标（C2ST 0.744/0.804 全场最低、复制率 0%/0.3%、病灶保留近 1），这些不随模型库变化。相对分只是方便展示，不是结论的支柱。结论的支柱是绝对指标 + Phase D 下游验证。

### Q6-2 考官："你承认病灶评估是颜色代理，那你的'病灶保留好'结论凭什么站得住？"
第一次答：因为我们是三层三角验证——颜色代理（病灶面积占比）+ Frangi（血管度）+ C2ST（整体像不像），三层的结论互相印证，泊松在三维都表现好。

考官再问："但你没有任何一张专家标注的 mask，你的'病灶'是自说自话。"
第二次答：是，我们没有 mask，所以全文用的是"病灶样内容"而非"病灶"。我们测的是"生成图里是否有足够多颜色/形态上像病灶的区域"，这是无标注场景能做的最强代理。真正的病灶语义验证在 Phase D——分类器对重度类的召回率。

考官再问："Phase D 还没做，你凭什么现在下结论？"
第三次答：现在没下"临床有效"的结论，只下"指标层面扩增候选"的结论。Phase D 是下一步，做完才能闭环。报告 8.5 明确写了这一步未做。

### Q6-3 考官："Retinex 只改光照，病灶/血管全继承底图，它到底'生成了什么'？"
第一次答：它生成了光照变化。底图 A 的解剖 + 供体 B 的光照 = 一张"解剖相同但采集条件不同"的新图。这在数据扩充里是真实价值：同一患者眼底在不同光照/设备下的变体，可以逼分类器学"光照不变性"。

考官再问："这不就是调亮度/调色温？跟 data augmentation 有什么区别？"
第二次答：有区别。旋转/裁剪是空间变换，亮度/对比度抖动是随机乘个系数，都会破坏光照和结构的物理一致性。Retinex 是"物理分解后只换光照层"——结构语义在交换前后保持（Laplacian 相关 0.52-0.84 验证），它生成的是"结构不变、光照物理上来自另一张真实图"的样本，不是随机噪声式抖动。简单说：它保证了光照和结构的耦合方式与真实采集一致。

考官再问："那它为什么只有 72.5，不是最高？"
第三次答：因为它的多样性主要在光照维度，结构维度没有新东西（1-NN 0.951、D6 记忆 0.099 都暴露了这一点），而且渗出保留率 0.44 偏低。它的定位是"安全多样化放大器"，不是"新解剖生成器"。72.5 和它"能做且只做光照交换"的定位一致。
