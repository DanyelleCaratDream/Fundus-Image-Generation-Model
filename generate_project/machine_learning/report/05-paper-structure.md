## 0. 章节定位与核心论点

**章节标题建议**：《补充实验：传统机器学习方法在眼底图生成上的边界与组合潜力》

**核心论点（一句话）**：
> 纯传统 ML（线性/密度/补丁）在小样本眼底生成上无法替代深度学习，但"结构+纹理+融合"的传统组合管线能产出深度无条件生成器难以显式控制的"新病灶组合"，作为数据扩充具有补充价值。

**两个子论点**：
1. **否定性**：纯传统 ML 基线（PCA/GMM/补丁）生成质量远低于扩散模型 → 证明深度生成的必要性，回应老师 Bug 2。
2. **建设性**：组合管线（泊松病变重排 / Retinex 光照交换）产出"相似但不相同"且几乎不改诊断语义的图 → 传统 ML 有独特价值。

## 1. 章节结构

### 引言（半页）
- 老师 Bug 2：方法不限于深度学习。
- 问题：非深度方法能否生成"相似但不相同"的重度眼底图？
- 本补充实验的定位：对照 + 组合探索。

### 方法一：传统 ML 方法谱系与可行性分析（1 页）
- 三路文献调研摘要：18 法谱系 → 三档可行性（高/中/低）。
- 关键判断：参数化模型必败于非高斯+强结构；非参数补丁法保纹理不保全局。
- 参考：`report/01-literature-trad-ml.md`。

### 方法二：确定性基线实验（1-1.5 页）
- 3 个基线：PCA 线性重建 / GMM 混合采样 / 补丁拼接。
- 数据口径：330 张真实图，128×128；3 基线各 300 张（已完成），组合方法 60 张（2026-08-18 新规）。
- 评估：统一两层指标体系 + 六维综合评分。
- **预期结果**：得分远低于扩散模型（预期 0-20 分），证否"纯传统 ML 可生成"。

### 方法三：高价值组合实验（1-1.5 页）
- 2 个组合：泊松病变重排（Yu 2021）/ Retinex 光照交换（Zhang 2022）。
- 数据口径：同上，各生成 60 张（新规）。
- 评估：同上 + 复制检测三件套（相似但不相同的验证）。
- **预期结果**：复制率低、病灶保留好；综合分高于纯基线但低于扩散最佳；体现"新病灶组合"价值。

### 结果与讨论（1 页）
- 横向对比表：3 传统基线 + 2 组合 + 6 深度方法，统一评分。
- 诚实结论：传统组合≠替代深度，是补充；生成 vs 增广的价值定位（增广证据链）。
- 局限：无真实病灶 mask（病变模板用颜色阈值近似）、补丁法局部复制风险、330 张小样本。

### 结论（半页）
- 纯传统 ML 无生成价值（否定性证据链完整）。
- 组合管线有独特价值：显式控制新病灶组合。
- 下一步：组合结果进入 Phase D 分类器验证（TSTR/TRTR）。

## 3. 贡献点（写进论文的话术）

1. **系统盘点**：首次对 18 种传统 ML/经典 CV 图像生成方法在小样本重度眼底图上的可行性做统一评估（含文献证据链）。
2. **组合范式**：提出"结构层 + 纹理层 + 融合层 + 多样化层"的传统 ML 组合管线（对应设计规范 `docs/03`）。

4. **诚实边界**：给出"生成 vs 增广"的文献定位（生成不追求超越增广的判别力，锚定在"新病灶组合"）。
