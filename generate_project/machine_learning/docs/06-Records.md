## EX-004：泊松贴片重排（v6 增强版）

- **日期**：2026-08-03
- **方法**：泊松贴片融合（融合层，零病灶检测）。跨图无缝搬运病灶样纹理：底图 A + 供体 B 贴片（`cv2.seamlessClone` NORMAL_CLONE）+ 全局旋转/色彩微变换
- **文献依据**：report/03-literature-fusion.md + Yu et al. 2021 (Biomed Opt Express)
- **关键设计决策**（六段式过程记录）：
  - 病灶检测启发式（局部对比度）验证失败 → 方法不需要知道"哪块是病灶"，随机椭圆贴片簇（r60-150px @512）即可搬运病灶样内容
  - **v1 近复制事故**：贴片小（1-6% 像素）→ mem_ssim 0.942 / 复制率 96.7% → 触发门控
  - **v6 增强重排**（用户拍板）：10 贴片 + 旋转 ±15° + 色彩 ±18% → 复制率归零
- **超参数**：seed=42, img_size=128, work_size=512, num_images=300, max_patches=10, patch_radius=100, rot=15, color_jit=0.18
- **运行命令**：
  ```
  python scripts/poisson_gen.py --num_images 300 --seed 42 --max_patches 10 --patch_radius 100 --rot 15 --color_jit 0.18
  ```
- **产出**：`eval_data/poisson/singles/`（300 张）+ 通用层/专用层 JSON + 蒙太奇 `_montage_v6/`
- **综合评分**（含门控）：
  - 六维：D1 0.97 / D2 0.96 / D3 0.91 / D4 1.00 / D5 1.00 / D6 0.00
  - 总分：**87.5 / 100**（全场第 1；用户确认有效，如实标注"高分部分源于底图复用 + min-max 相对分数"）
- **复制检测三件套**：mem_ssim 0.489（低于真实自身 0.548）｜ 复制率 **0.3%** ✅
- **关键指标**：FID 58.1（深度最佳 178）｜ C2ST 0.804（全场第 2 低）｜ BRISQUE 3.60≈真实 3.69 ｜ 病灶保留 出血 1.10/渗出 0.97 ｜ 血管 0.070 vs 0.077
- **质量观察**（肉眼抽查，用户 2026-08-03）：
  - 病灶保留：☑ 可辨 ｜ 血管结构：☑ 自然 ｜ 颜色：☑ 正常（蒙太奇 v6 用户确认"几乎看不出来是生成的"）
- **失败分析**（v1 近复制事故，已闭环）：
  - 现象：mem_ssim 0.942 / 复制率 96.7%
  - 原因假设：贴片太小只改 1-6% 像素 → 输出≈底图=近复制
  - 下一步：v6 增强重排（大贴片+全局微变换）→ 复制率归零，用户拍板后定案
- **结论**：☑ 有价值（进入下游验证候选）—— 真实感最强 + 非复制，但**生成新解剖结构弱**（底图血管/视盘/病灶布局不变），D6 记忆 0.00 是全场最接近真实集
- **对比**：与最佳深度方法（FiLM+L1+LPIPS）—— poisson 87.5 自动分 > film 47.4 自动分（film 人工分 87.5 巧合相等）；⚠️ 相对分数，模型库再扩会平移

## EX-005：Retinex 光照交换

- **日期**：2026-08-26（近复制拒绝方案 3 于 08-18 落地，08-26 全量复跑定稿；样本量按 2026-08-18 新规取 60 张）
- **方法**：Retinex 光照交换（多样化层，零结构检测）。经典单尺度 Retinex 分解 `log(图)=log(光照)+log(反射)`，跨图交换光照：`新图 = R_A · L_A^(1-α) · L_B^α`（α∈[0.6,0.9] 每张随机）
- **文献依据**：report/02 组合灵感 + Zhang, Li & Shin 2022 (Comput Biol Med 145:105427)——ID-Net 无监督 Retinex 增强光照层、保反射层 → 眼底分割超 SOTA 9.6% Dice；本脚本为无需网络的经典改编（跨图交换而非网络随机化）
- **关键设计决策**（六段式过程记录）：
  - **v0 亮度崩塌事故**：旧公式 `new = R_A · L_B^α` 只乘供体光照，α 压缩光照幅度（90^0.8≈36 而非 90）→ 输出近全黑（暗像素 97-99%），且 α=0 不还原底图。已改 log 域插值 `R_A · L_A^(1-α) · L_B^α`：α=0 完美还原（max err 0）、α=1 纯交换、α=0.8 亮度 144 vs 底图 150
  - **近复制风险 → 方案 3 过滤**（用户 2026-08-18 确认）：光照交换只改光照不改结构，α 低 + 供体光照≈底图时输出≈底图（60 张实测 1 张 NN-SSIM 0.891）。新增生成后过滤：与 330 张真实图算 NN-SSIM（pytorch_msssim，评估同口径），>0.85 重采样（max_retry 20）→ 复制率 1.7%→0（中位 NN-SSIM 0.616 基本不动，只剔尾部）
  - **结构归属验证**：Laplacian（高频）相关跟随底图（0.52-0.84）、整图灰度相关跟随供体光照 → 内部结构语义不变、光照包络变 = "相似但不相同"正确行为
- **超参数**：seed=42, img_size=128, work_size=512, num_images=60（新规）, kernel=41, α∈[0.6,0.9], mem_thr=0.85, max_retry=20
- **运行命令**：
  ```
  python scripts/retinex_gen.py --num_images 60 --seed 42 --kernel 41 --alpha_lo 0.6 --alpha_hi 0.9 --mem_ref ../../eval_data/real --mem_thr 0.85 --max_retry 20
  ```
- **产出**：`eval_data/retinex/singles/`（60 张）+ 通用层/专用层 JSON + 蒙太奇 `_montage/`（donor|base|output 对比条）
- **综合评分**（含门控，11 模型现版）：
  - 六维：D1 0.94 / D2 0.82 / D3 0.72 / D4 0.92 / D5 0.92 / D6 0.10
  - 总分：**72.5 / 100**（全场第 2；同版 poisson 80.8、film_l1lpips 45.2）
- **复制检测三件套**：NN-SSIM 最近邻 max **0.825**（<0.85 ✅）｜ 全图复制率 **0%** ✅（方案 3 过滤后归零）
- **关键指标**：FID 117.9 / KID 0.056（全场最低，**如实标注：高分部分源于底图复用**）｜ C2ST AUC **0.744**（**全场最佳**，最难被识破）｜ BRISQUE 3.70≈真实 3.69 ｜ 病灶保留 出血 1.06/渗出 0.44（渗出偏低）｜ 血管 0.071 vs 真实 0.077
- **质量观察**：血管结构自然（继承底图）｜ 亮度中位 77（真实 61，部分图偏暗——供体光照特性）
- **失败分析**（v0 亮度崩塌 + 近复制，均已闭环）：
  - 现象：输出近全黑（暗像素 97-99%）；60 张 1 张 NN-SSIM 0.891 近复制
  - 原因假设：v0 公式压缩光照幅度；光照交换天然保留底图结构
  - 下一步：log 域插值公式修复 + 方案 3 生成后过滤 → 全闭环验证通过
- **结论**：☑ 有价值（进入下游验证候选）—— 抗识破全场最佳 + 复制归零 + BRISQUE≈真实；但**平均 NN-SSIM 0.439 偏高**（光照交换天然保留底图结构）→ D6 记忆 0.10 弱项，如实记录
- **对比**：与最佳深度方法（FiLM+L1+LPIPS，现版 45.2 自动分）—— retinex 72.5 大幅领先；⚠️ 相对分数 + 高分部分源于底图复用（同 poisson），报告如实标注
