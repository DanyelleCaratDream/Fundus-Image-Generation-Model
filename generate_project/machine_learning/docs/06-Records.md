## EX-004：泊松贴片重排（v6 增强版）

- **日期**：2026-08-03
- **方法**：泊松贴片融合（融合层，零病灶检测）。跨图无缝搬运病灶样纹理：底图 A + 供体 B 贴片（`cv2.seamlessClone` NORMAL_CLONE）+ 全局旋转/色彩微变换
- **文献依据**：report/03-literature-fusion.md + Yu et al. 2021 (Biomed Opt Express)
- **关键设计决策**（六段式过程记录）：
  - 病灶检测启发式（局部对比度）验证失败 → 方法不需要知道"哪块是病灶"，随机椭圆贴片簇（r60-150px @512）即可搬运病灶样内容
  - **v1 近复制事故**：贴片小（1-6% 像素）→ mem_ssim 0.942 / 复制率 96.7% → 触发门控
  - **v6 增强重排**（用户拍板）：10 贴片 + 旋转 ±15° + 色彩 ±18% → 复制率归零
- **超参数**：seed=42, img_size=128, work_size=512, num_images=300, max_patches=10, patch_radius=100, rot=15, color_jit=0.18
- **运行命令**：
  ```
  python scripts/poisson_gen.py --num_images 300 --seed 42 --max_patches 10 --patch_radius 100 --rot 15 --color_jit 0.18
  ```
- **产出**：`eval_data/poisson/singles/`（300 张）+ 通用层/专用层 JSON + 蒙太奇 `_montage_v6/`
- **综合评分**（含门控）：
  - 六维：D1 0.97 / D2 0.96 / D3 0.91 / D4 1.00 / D5 1.00 / D6 0.00
  - 总分：**87.5 / 100**（全场第 1；用户确认有效，如实标注"高分部分源于底图复用 + min-max 相对分数"）
- **复制检测三件套**：mem_ssim 0.489（低于真实自身 0.548）｜ 复制率 **0.3%** ✅
- **关键指标**：FID 58.1（深度最佳 178）｜ C2ST 0.804（全场第 2 低）｜ BRISQUE 3.60≈真实 3.69 ｜ 病灶保留 出血 1.10/渗出 0.97 ｜ 血管 0.070 vs 0.077
- **质量观察**（肉眼抽查，用户 2026-08-03）：
  - 病灶保留：☑ 可辨 ｜ 血管结构：☑ 自然 ｜ 颜色：☑ 正常（蒙太奇 v6 用户确认"几乎看不出来是生成的"）
- **失败分析**（v1 近复制事故，已闭环）：
  - 现象：mem_ssim 0.942 / 复制率 96.7%
  - 原因假设：贴片太小只改 1-6% 像素 → 输出≈底图=近复制
  - 下一步：v6 增强重排（大贴片+全局微变换）→ 复制率归零，用户拍板后定案
- **结论**：☑ 有价值（进入下游验证候选）—— 真实感最强 + 非复制，但**生成新解剖结构弱**（底图血管/视盘/病灶布局不变），D6 记忆 0.00 是全场最接近真实集
- **对比**：与最佳深度方法（FiLM+L1+LPIPS）—— poisson 87.5 自动分 > film 47.4 自动分（film 人工分 87.5 巧合相等）；⚠️ 相对分数，模型库再扩会平移
