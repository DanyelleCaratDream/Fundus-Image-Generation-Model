# 眼底彩照项目 · 科研开发文档体系

> 版本：v0.1 | 维护人：项目组全体 | 评审人：导师
> 最近更新：____-__-__

## 一、项目一句话描述

基于生成模型（当前最优路线：Diffusion + 自有改进方法）对严重症状眼底彩照进行数据扩充，
训练症状分级分类器，最终产出高水平学术论文。

## 三、文档使用规则

1. **编号即优先级**：01~07 为建立顺序，越靠前越先完成。
2. **变更留痕**：所有文档用 Git 管理，修改走 commit，重大修改在文档末尾"修订记录"表中登记。
3. **评审节点**（建议）：
   - 研究提案 + DMP + 伦理 → 项目启动前评审
   - 技术路线 + 设计规范 → 进入实验前评审
   - 实验记录 → 每周检查一次完整性
   - 模型卡 + 复现指南 → 投稿前必须完成
4. **填写约定**：正文中所有 `____` 与【待填写】为占位符，填写后删除标记。
